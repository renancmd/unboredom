# 🎮 Unboredom

## 📝 Descrição

**Unboredom** é uma aplicação web que oferece **mini jogos para jogar quando estiver entediado**. A proposta do projeto é ser uma coleção leve e divertida de jogos simples e rápidos.

Atualmente, a aplicação conta com o jogo **Wordle** (adivinhação de palavras).

---

## 💻 Tecnologias Utilizadas

- HTML
- CSS
- JavaScript

---

## 🎲 Mini Jogos Disponíveis

- ✅ **Wordle** – descubra a palavra do dia em até 6 tentativas
